      뜻풀이

      쉬운 AI 사전

      1. [명사] (도구) 거대 언어 모델에 검색, 계산기, 외부 서비스를 연결해 쓸 수 있게 해 주는 개발 도구.

      실무 AI 사전

      1. [명사] (도구) 프롬프트 템플릿, 모델 호출, 문서 검색, 도구 사용, 대화 기록 관리를 부품처럼 조립해 LLM 앱을 만드는 오픈소스 프레임워크. 프로토타입을 빠르게 만들기 좋지만 추상화가 두꺼워 운영 단계에서는 직접 구현으로 바꾸기도 한다.

      전문 AI 사전

      1. [명사] (도구) LLM 애플리케이션 개발용 파이썬/자바스크립트 프레임워크로 체인(순차 호출), 리트리버, 에이전트, 메모리 모듈과 여러 모델 제공자 연동을 표준 인터페이스로 제공한다. 상태 기반 에이전트 흐름을 위한 LangGraph가 별도 라이브러리로 있다.

      관용구/함께 쓰는 말

      • 체인 - 여러 호출을 순서대로 이어 붙인 처리 단위.
      • 리트리버 - 질문과 관련된 문서를 찾아오는 부품.

      쉬운 비유

      레고 설명서와 부품 세트가 같이 들어 있는 상자와 같다. 검색, 기억, 계산기 블록을 꽂아 챗봇 완성품을 만든다.

      예문

      • 랭체인으로 사내 문서 검색 챗봇의 시제품을 하루 만에 만들었다.
      • 랭체인 버전이 바뀌어서 예전 코드가 그대로 돌아가지 않는다.
      • 프롬프트와 검색을 랭체인 체인으로 이어 붙였다.

      헷갈리는 용어 비교

      에이전트
      랭체인은 LLM 앱을 만드는 도구 상자이고, 에이전트는 AI가 스스로 계획하고 도구를 골라 쓰는 동작 방식이다. 랭체인으로 에이전트를 만들 수도, 단순한 고정 흐름을 만들 수도 있다.
