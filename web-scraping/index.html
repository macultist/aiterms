      웹 스크래핑

      web scraping실무

      다른 이름: 스크래핑, 웹스크래핑, 웹 데이터 추출, 스크레이핑, web scraper

      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 웹 페이지에서 필요한 정보(가격, 제목 등)만 자동으로 뽑아 내는 일.

      실무 AI 사전

      1. [명사] (데이터) 상품 가격 비교, 뉴스 제목 수집, 공개 통계 수집 등에 쓴다. HTML 구조가 바뀌면 코드가 깨지고, 이용약관이나 저작권, 개인정보를 어기지 않았는지 먼저 확인해야 한다. 공식 API가 있으면 API가 우선이다.

      전문 AI 사전

      1. [명사] (데이터) HTML 문서를 내려받아 DOM 선택자(CSS, XPath)로 특정 요소를 추출해 구조화된 데이터로 변환하는 기법. 동적 페이지는 헤드리스 브라우저로 렌더링한 뒤 추출하며, 요청 빈도 제한과 접근 규약 준수가 전제다.

      관용구/함께 쓰는 말

      • CSS 선택자 - HTML에서 요소를 골라내는 규칙.
      • 헤드리스 브라우저 - 화면 없이 동작하는 브라우저 프로그램.

      쉬운 비유

      신문에서 필요한 기사만 가위로 오려 내는 것과 같다. 전체를 돌아다니는 게 아니라 필요한 내용만 뽑는다.

      예문

      • 쇼핑몰 가격을 웹 스크래핑하려다 이용약관에서 금지하는 걸 보고 공식 API를 쓰기로 했다.
      • 페이지 구조가 바뀌어서 스크래핑 코드가 갑자기 값을 못 뽑았다.
      • 동적으로 그려지는 페이지는 브라우저를 띄워서 스크래핑해야 한다.

      헷갈리는 용어 비교

      웹 크롤링
      스크래핑은 페이지 안에서 원하는 정보를 꺼내는 일에 초점을 두고 크롤링은 페이지를 찾아 돌아다니는 일에 초점을 둔다.
