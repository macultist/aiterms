      뜻풀이

      쉬운 AI 사전

      1. [명사] (코딩) 글자 덩어리를 규칙에 따라 읽어서 의미 있는 조각으로 나누는 일. 문장을 주어, 서술어로 나누는 것과 비슷하다.

      실무 AI 사전

      1. [명사] (코딩) JSON, HTML, 로그, PDF 같은 원본에서 필요한 필드를 뽑아내는 작업이다. LLM 응답이 정해진 형식이 아니면 파싱이 실패하므로, 구조화된 출력으로 형식을 강제하는 경우가 많다.

      전문 AI 사전

      1. [명사] (코딩) 입력 문자열을 문법에 따라 구문 트리 같은 구조적 표현으로 변환하는 과정. 프로그래밍 언어와 데이터 형식에서는 토큰화 후 문법 규칙을 적용하며, 자연어 처리에서는 문장의 구문 구조를 분석하는 구문 분석을 말한다.

      관용구/함께 쓰는 말

      • 파싱 오류 - 형식이 맞지 않아 읽지 못하는 오류.
      • JSON 파서 - JSON 문자열을 데이터 구조로 바꿔 주는 프로그램.

      쉬운 비유

      외국어 문장을 읽고 단어와 문법 구조로 쪼개서 뜻을 파악하는 것과 같다.

      예문

      • LLM이 준 JSON이 깨져서 파싱 에러가 났다.
      • HTML을 파싱해서 제목과 가격만 추출했다.
      • PDF는 레이아웃이 복잡해서 파싱 품질이 문서마다 달랐다.

      헷갈리는 용어 비교
