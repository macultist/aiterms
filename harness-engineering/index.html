      하네스 엔지니어링

      harness engineering실무

      다른 이름: 에이전트 하네스, 하네스 설계

      뜻풀이

      쉬운 AI 사전

      1. [명사] (에이전트) AI 모델은 그대로 두고, 모델이 쓰는 도구, 권한, 규칙 파일, 자동 검사 같은 주변 장치를 잘 짜서 에이전트의 성능과 안전을 끌어올리는 일.

      실무 AI 사전

      1. [명사] (에이전트) 에이전트를 감싸는 실행 환경(하네스)을 설계하는 일. 어떤 도구를 쓸 수 있는지, 어디까지 권한을 줄지, 어떤 규칙 문서를 읽게 할지, 결과를 어떻게 자동으로 검사하고 되돌릴지를 정한다. 같은 모델이라도 하네스에 따라 결과 품질이 크게 달라진다.

      관용구/함께 쓰는 말

      • 에이전트 하네스 - 에이전트가 일하는 틀. 도구 목록, 권한, 규칙, 검사 절차를 묶어 부르는 말.

      쉬운 비유

      같은 요리사라도 주방 동선, 칼, 레시피 카드, 맛보기 절차를 어떻게 갖추느냐에 따라 결과가 달라지는 것과 같다. 요리사(모델)를 바꾸지 않고 주방(하네스)을 고치는 일이다.

      예문

      • 모델을 바꾸는 대신 하네스 엔지니어링으로 테스트 자동 실행을 붙였더니 오류가 절반으로 줄었다.
      • 코딩 에이전트 도입 팀은 프롬프트보다 하네스 엔지니어링에 시간을 더 쓰고 있다.

      헷갈리는 용어 비교

      프롬프트 엔지니어링
      프롬프트 엔지니어링은 모델에게 보내는 글을 다듬는 일이고, 하네스 엔지니어링은 모델 바깥의 도구, 권한, 검사 장치를 설계하는 일이다. 글 한 번이 아니라 일하는 환경 전체를 다룬다.
      컨텍스트 엔지니어링
      컨텍스트 엔지니어링은 모델에게 어떤 정보를 어떤 순서로 넣을지 정하는 일이고, 하네스 엔지니어링은 그것까지 포함해 도구와 권한, 자동 검사 같은 실행 틀 전체를 설계한다. 하네스가 더 넓은 말이다.
