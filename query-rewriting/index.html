      쿼리 재작성

      query rewriting실무

      다른 이름: 질의 재작성, 쿼리 리라이팅, query rewrite, 질문 재작성, query reformulation

      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 사용자가 던진 애매하거나 짧은 질문을 검색이 잘 되게 고쳐 쓰는 일.

      실무 AI 사전

      1. [명사] (데이터) '그거 환불돼요?' 같은 질문을 이전 대화를 반영해 '주문한 신발 환불 가능 여부'로 바꿔 검색한다. RAG에서 맞는 문서를 못 찾는 문제를 줄이는 첫 단계다.

      전문 AI 사전

      1. [명사] (데이터) 원 질의를 검색기에 더 적합하도록 변환하는 전처리. 대화 맥락을 반영한 독립 질의 생성, 약어 확장, 다중 질의 생성, 가상 문서 생성(HyDE) 등이 포함된다. 보통 LLM에게 재작성을 시키며 지연과 비용이 추가된다.

      관용구/함께 쓰는 말

      • 쿼리 확장 - 비슷한 말이나 관련어를 덧붙여 검색 범위를 넓히는 일.
      • 다중 질의 - 한 질문을 여러 표현으로 만들어 동시에 검색하는 방식.

      쉬운 비유

      도서관 사서가 손님의 '그 파란 책 있어요?'를 '3월에 반납된 파란 표지 요리책'으로 바꿔 검색창에 입력하는 것과 같다.

      예문

      • 대화 맥락을 넣어 쿼리 재작성을 하자 '그거 얼마예요'가 제품명이 들어간 질문으로 바뀌었다.
      • 쿼리 재작성으로 하나의 질문을 세 가지 표현으로 만들어 검색 누락을 줄였다.
      • 재작성 결과가 원래 의도와 달라지는지 로그로 확인해야 한다.

      헷갈리는 용어 비교

      쿼리 확장
      쿼리 확장은 비슷한 말을 덧붙여 범위를 넓히는 방식이고, 쿼리 재작성은 질문 자체를 더 명확하고 검색에 알맞은 문장으로 다시 쓰는 방식이다. 확장은 재작성의 한 방법이 될 수 있다.
      프롬프트 엔지니어링
      프롬프트 엔지니어링은 모델에 줄 지시를 다듬는 일이고, 쿼리 재작성은 검색 단계에 들어갈 사용자의 질문을 고치는 일이다.
