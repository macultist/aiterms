      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『인프라』 프로그램끼리 서로 기능을 주고받는 창구. AI 회사가 API를 열어 두면 다른 앱에서 그 AI를 불러 쓸 수 있다.

      실무 AI 사전

      1. 「명사」 『인프라』 LLM 제공사가 HTTP로 노출하는 모델 호출 인터페이스. 토큰 단위로 과금되며 키 관리, 요청 제한(rate limit), 비용 모니터링이 운영 과제다.

      관용구/함께 쓰는 말

      • API 키 — API를 쓸 권한을 증명하는 비밀 문자열. 외부에 노출하면 안 된다.

      쉬운 비유

      식당의 주문 창구와 같다. 손님은 주방에 들어가지 않고 메뉴를 말해 주문하고, 완성된 요리만 받는다.

      예문

      • 우리 앱은 API로 클로드를 불러 답변을 만든다.
      • 챗봇 기능은 직접 만들지 않고 외부 AI 서비스의 API를 연결해 하루 만에 붙였다.

      헷갈리는 용어 비교

      SDK
      API는 서비스를 호출하는 규칙과 창구이고, SDK는 그 API를 편하게 쓰도록 언어별로 만들어 둔 도구 모음이다. 같은 API라도 SDK를 쓰면 코드가 짧아지고 직접 요청을 만들지 않아도 된다.
      API 키
      API는 호출하는 창구이고, API 키는 그 창구를 쓸 자격을 증명하는 비밀 문자열이다. 키가 유출되면 다른 사람이 내 비용으로 호출할 수 있어 관리가 중요하다.
