      모델 레지스트리

      model registry실무

      다른 이름: 모델 저장소, 모델 등록소, 모델 레지스트리 서비스

      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『인프라』 학습을 끝낸 AI 모델의 버전과 상태를 기록해 두는 보관소. 어떤 것을 서비스에 쓸지 정하는 장부다.

      실무 AI 사전

      1. 「명사」 『인프라』 모델 파일, 학습 데이터 버전, 평가 점수, 승인 상태를 함께 기록해 어떤 모델이 지금 운영 중인지 추적하는 곳. 문제가 생기면 이전 버전으로 되돌리기 쉽고 누가 언제 승인했는지 감사 기록이 남는다.

      전문 AI 사전

      1. 「명사」 『인프라』 모델 아티팩트와 메타데이터(학습 코드 커밋, 하이퍼파라미터, 지표)를 버전별로 저장하고 스테이징, 프로덕션, 보관 같은 수명 주기 단계를 관리하는 중앙 저장소. 배포 파이프라인과 연동되어 승인된 버전만 운영에 오르게 한다.

      관용구/함께 쓰는 말

      • 모델 등록 — 학습한 모델을 버전과 함께 레지스트리에 남기는 것.
      • 스테이징 — 본 서비스에 올리기 전 시험 환경에 두는 단계.

      쉬운 비유

      도서관의 장서 목록과 같다. 책(모델)이 몇 판인지, 어느 서가에 있는지, 대출 중인지 한눈에 알 수 있다.

      예문

      • 평가를 통과한 모델은 레지스트리에 등록한 뒤에만 배포할 수 있다.
      • 모델 레지스트리를 보니 지금 운영 중인 모델은 3주 전 버전이다.
      • 문제가 생겨서 레지스트리에 있는 이전 버전으로 돌려놓았다.

      헷갈리는 용어 비교

      실험 추적
      실험 추적은 학습 시도마다의 설정과 점수를 기록해 무엇이 좋았는지 비교하는 일이고, 모델 레지스트리는 그중 뽑힌 모델을 운영 후보로 관리하는 일이다. 실험이 수십 번이라면 레지스트리에는 선택된 몇 개만 오른다.
