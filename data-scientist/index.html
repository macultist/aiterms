      데이터 사이언티스트

      data scientist실무

      다른 이름: 데이터 과학자, 데이터사이언티스트

      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『데이터』 데이터를 분석하고 예측 모델을 만들어 회사의 문제를 푸는 직업.

      실무 AI 사전

      1. 「명사」 『데이터』 업무 문제를 데이터 질문으로 바꾸고 분석, 실험 설계, 모델링을 맡는다. 회사에 따라 분석가와 비슷하게 일하기도 하고 머신러닝 모델 개발에 더 가깝게 일하기도 한다.

      전문 AI 사전

      1. 「명사」 『데이터』 통계, 머신러닝, 프로그래밍(Python, SQL)을 갖추고 비즈니스 문제를 정량적으로 정식화하는 직무다. 결과를 이해관계자가 쓰도록 전달하는 역량도 요구된다.

      관용구/함께 쓰는 말

      • 데이터 사이언티스트 채용 — 분석과 모델링 인력을 뽑는 일.
      • 데이터 팀 — 분석과 엔지니어링 담당이 모인 조직.

      쉬운 비유

      병원의 의사와 비슷하다. 환자(데이터)의 상태를 살피고 원인을 추리해 치료 방향(모델과 결론)을 제안한다.

      예문

      • 데이터 사이언티스트가 이탈 예측 모델의 정확도를 높이는 실험을 했다.
      • 우리 팀에는 데이터 사이언티스트 두 명과 엔지니어 한 명이 있다.
      • 데이터 사이언티스트는 결과를 설명하는 능력이 모델 만들기만큼 중요하다.

      헷갈리는 용어 비교

      데이터 엔지니어
      데이터 사이언티스트는 데이터를 분석하고 모델링하는 사람이고, 데이터 엔지니어는 그 데이터를 모아 믿고 쓸 수 있게 흘려보내는 시스템을 만드는 사람이다. 보통 엔지니어가 길을 닦고 사이언티스트가 그 위에서 일한다.
      ML 엔지니어
      데이터 사이언티스트가 실험과 분석에 가깝다면 ML 엔지니어는 모델을 서비스에 올려 안정적으로 돌리는 일에 가깝다.
