      ReAct

      reasoning and acting전문

      다른 이름: 리액트 프롬프팅, reason+act, 추론 행동 결합

      뜻풀이

      쉬운 AI 사전

      1. [명사] (에이전트) AI가 '생각하고, 행동하고, 결과를 보고 다시 생각하기'를 번갈아 하며 문제를 푸는 방식.

      실무 AI 사전

      1. [명사] (에이전트) 검색이나 계산기 같은 도구를 쓰면서 한 단계씩 추론을 적게 한다. 도구 결과를 보고 다음 행동을 정하기 때문에 최신 정보가 필요하거나 여러 단계가 필요한 질문에서 에이전트의 기본 뼈대로 쓴다.

      전문 AI 사전

      1. [명사] (에이전트) 추론(Thought)과 행동(Action), 관찰(Observation)을 교대로 생성하게 하는 프롬프팅 패러다임. 추론이 행동 계획을 세우고 관찰이 다음 추론을 갱신하도록 만들어 도구 사용과 사고 과정을 하나의 흐름으로 묶는다. 2022년 논문에서 제안됐다.

      관용구/함께 쓰는 말

      • ReAct 루프 - 생각, 행동, 관찰을 반복하는 구조.
      • 관찰 단계 - 도구를 실행한 결과를 모델이 읽는 단계.

      쉬운 비유

      요리사가 '다음엔 뭘 넣지?'라고 생각하고, 간을 보고, 맛을 확인한 뒤 다시 생각하는 과정을 반복하는 것과 같다.

      예문

      • ReAct 방식으로 '생각, 검색, 관찰'을 반복시켜 여러 문서를 오가며 답을 찾게 했다.
      • 도구가 잘못된 결과를 주면 ReAct 루프가 그 오류를 믿고 끝까지 끌고 가서 결과가 틀어졌다.
      • 에이전트 프레임워크 대부분이 ReAct 루프를 기본으로 깔고 있다.

      헷갈리는 용어 비교

      사고 연쇄
      사고 연쇄는 모델이 속으로만 단계별 추론을 쓰고 외부 세계는 보지 않는다. ReAct는 추론 사이에 도구 호출 같은 행동을 끼워 바깥의 정보를 가져온다.
      도구 호출
      도구 호출은 모델이 함수를 부르는 기능 자체이고, ReAct는 그 기능을 추론과 번갈아 쓰는 방식을 정한 패턴이다.
