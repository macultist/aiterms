      meta-learning전문

      다른 이름: Meta-learning, 메타러닝, 학습하는 법 학습, learning to learn

      뜻풀이

      쉬운 AI 사전

      1. [명사] (학습) 여러 문제를 풀어 보며 새 문제를 빨리 배우는 요령 자체를 배우는 방법. '학습하는 법을 학습한다'고 한다.

      실무 AI 사전

      1. [명사] (학습) 새 작업마다 라벨이 몇 개밖에 없는 상황에서 적은 예시만으로 적응하는 모델을 만들 때 쓴다. 퓨샷 학습 연구의 대표 접근이지만, 구현이 까다로워 실무 도입은 드물다.

      전문 AI 사전

      1. [명사] (학습) 작업 분포에서 여러 학습 에피소드를 샘플링해 새 작업에 빠르게 적응하는 초기값이나 학습 규칙을 얻는 방법이다. MAML처럼 소수 경사 스텝 후 성능이 좋아지도록 초기 파라미터를 최적화하는 방식과, 프로토타입 네트워크처럼 거리 기반으로 분류하는 방식이 있다. 대형 언어모델의 인컨텍스트 학습을 메타 학습의 관점으로 보기도 한다.

      관용구/함께 쓰는 말

      • 에피소드 - 메타 학습에서 작은 학습 과제와 평가 과제를 한 쌍으로 묶은 훈련 단위.
      • N-way K-shot - N개 클래스를 클래스당 K개의 예시만으로 구분하는 설정.

      쉬운 비유

      여러 과목의 시험을 치러 보며, 과목이 달라도 통하는 공부 요령을 익힌 학생과 같다. 처음 보는 과목도 며칠 만에 따라잡는다.

      예문

      • 새 고객사마다 라벨이 열 개뿐이라 빠르게 적응하는 메타 학습 모델을 검토했다.
      • 메타 학습은 학습 작업을 여러 개 준비해 에피소드로 훈련한다.
      • MAML은 어떤 새 작업이든 몇 번만 고치면 잘 되는 초기 가중치를 찾는다.

      헷갈리는 용어 비교

      전이 학습
      전이 학습은 한 과제에서 배운 표현을 가져다 쓰고, 메타 학습은 새 과제에 빨리 적응하는 능력 자체를 여러 과제를 통해 훈련한다.
