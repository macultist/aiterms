      parameter실무

      다른 이름: 매개변수, 가중치 수

      뜻풀이

      쉬운 AI 사전

      1. [명사] (모델) AI 모델이 학습하면서 조정하는 숫자들. '파라미터 700억 개'처럼 모델의 크기를 나타낼 때 쓴다.

      실무 AI 사전

      1. [명사] (모델) 모델의 학습 가능한 가중치와 편향의 총수. 많을수록 성능이 좋아지는 경향이 있지만 메모리, 비용, 속도 부담도 커진다.

      전문 AI 사전

      1. [명사] (모델) 경사 하강법으로 갱신되는 모델 내부 변수. 7B, 70B처럼 B(10억) 단위로 표기하며, 하이퍼파라미터(학습률 등)와 구별한다.

      쉬운 비유

      악기의 수많은 조율 나사와 비슷하다. 학습하면서 나사를 조금씩 돌려 소리를 맞추듯, 모델은 숫자를 조금씩 고쳐 정답에 가까워진다.

      예문

      • 파라미터가 4,050억 개인 모델을 돌리려면 GPU가 여러 장 필요하다.
      • 파라미터 수가 많다고 항상 더 좋은 모델인 것은 아니라는 점을 발표에서 짚었다.

      헷갈리는 용어 비교

      토큰
      파라미터는 모델 내부에 저장된 학습 결과 숫자이고, 토큰은 모델이 읽고 쓰는 글 조각이다. 파라미터는 모델 크기를, 토큰은 입력과 출력 길이를 말할 때 쓴다.
      학습
      학습은 데이터를 보며 모델을 고쳐 가는 과정이고, 파라미터는 그 과정에서 실제로 바뀌는 숫자들이다. 학습의 결과물이 곧 파라미터에 담긴다.
