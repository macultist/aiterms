      센서 퓨전

      sensor fusion전문

      다른 이름: 센서 융합, 센서퓨전, 다중 센서 융합, 멀티센서 퓨전

      뜻풀이

      쉬운 AI 사전

      1. [명사] (로봇) 카메라, 레이더, 라이다처럼 여러 센서 정보를 합쳐 한 센서만 쓸 때보다 정확하게 파악하는 기술.

      실무 AI 사전

      1. [명사] (로봇) 자율주행, 드론, 로봇, 스마트폰의 위치 추정에서 각 센서의 약점을 서로 보완하는 데 쓴다. 센서 시간 동기화와 좌표 정렬이 실무에서 큰 품이 든다.

      전문 AI 사전

      1. [명사] (로봇) 서로 다른 센서의 측정치를 칼만 필터 같은 확률적 상태 추정이나 딥러닝으로 융합해 불확실성을 줄이는 기법이다. 입력 단계, 특징 단계, 결정 단계로 융합 시점을 나누며 시간 동기화와 외부 보정(캘리브레이션)이 전제다.

      관용구/함께 쓰는 말

      • 칼만 필터 - 센서 측정의 잡음을 줄여 상태를 추정하는 알고리즘.
      • 캘리브레이션 - 센서 위치와 오차를 보정하는 과정.

      쉬운 비유

      눈, 귀, 코가 각각 알려 준 정보를 뇌가 합쳐서 상황을 정확히 아는 것과 같다.

      예문

      • 자율주행차는 카메라와 라이다를 센서 퓨전으로 합쳐 야간에도 보행자를 인식한다.
      • 센서 퓨전에서는 센서마다 시간이 어긋나지 않게 맞추는 일이 중요하다.

      헷갈리는 용어 비교

      멀티모달
      멀티모달은 텍스트, 이미지, 음성 같은 여러 형식을 AI가 함께 다루는 일이고, 센서 퓨전은 물리 센서 데이터를 합쳐 현실을 파악하는 일이다.
