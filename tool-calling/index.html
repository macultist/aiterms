      도구 호출

      tool calling실무

      다른 이름: 함수 호출, 펑션 콜링, 툴 콜링, tool use

      뜻풀이

      쉬운 AI 사전

      1. [명사] (에이전트) AI가 계산기, 검색, 달력 같은 외부 기능을 스스로 불러 쓰는 것.

      실무 AI 사전

      1. [명사] (에이전트) 모델이 정해진 형식(JSON)으로 함수 이름과 인자를 출력하면 애플리케이션이 실행하고 결과를 돌려주는 방식. 에이전트 구현의 기본 요소다.

      쉬운 비유

      계산을 못 하는 사람이 필요할 때 계산기를 꺼내 쓰는 것과 같다. AI는 직접 실행하지 못하니 무엇을 써 달라고 요청서를 쓰고, 프로그램이 실제로 실행한 결과를 받아 답한다.

      예문

      • 도구 호출을 붙이면 AI가 실시간 환율도 조회할 수 있다.
      • 날씨를 물으면 모델이 도구 호출로 기상 조회 함수를 부르고 그 결과를 문장으로 풀어 준다.

      헷갈리는 용어 비교

      MCP
      도구 호출은 모델이 도구를 불러 달라고 요청하는 동작이고, MCP는 도구를 연결하는 방식을 통일한 공통 규격이다. 도구마다 연결 코드를 새로 짜지 않게 해 주는 것이 MCP다.
      API
      API는 프로그램이 기능을 호출하는 창구이고, 도구 호출은 AI 모델이 그 창구를 쓰겠다고 정해진 형식으로 요청하는 방식이다. 모델이 직접 API를 실행하는 것이 아니라 애플리케이션이 대신 실행한다.
