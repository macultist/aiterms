      선호 데이터

      preference data실무

      다른 이름: 선호도 데이터, 선호 쌍 데이터, preference pairs, 프리퍼런스 데이터

      뜻풀이

      쉬운 AI 사전

      1. [명사] (학습) 같은 질문에 대한 두 답 중 사람이 '이쪽이 더 낫다'고 고른 기록을 모은 자료.

      실무 AI 사전

      1. [명사] (학습) 보상 모델과 DPO 학습의 재료다. 같은 프롬프트에 서로 다른 답을 두 개 이상 만들어 평가자가 고르게 해 모으며, 평가 기준이 흔들리면 모델의 방향도 흔들린다.

      전문 AI 사전

      1. [명사] (학습) 프롬프트와 선택된 응답(chosen), 거절된 응답(rejected)의 쌍으로 이루어진 데이터. 사람 평가자나 더 강한 모델이 라벨을 붙이며, 평가자 간 일치도와 기준 가이드라인이 데이터 품질을 좌우한다.

      관용구/함께 쓰는 말

      • 선택/거절 쌍 - 선호 데이터에서 고른 답과 버린 답의 짝.
      • 선호 라벨링 - 두 답 중 더 나은 쪽을 표시하는 작업.

      쉬운 비유

      맛집 블라인드 테스트에서 '두 접시 중 어느 쪽이 더 낫나요'를 수천 번 묻고 투표를 모아 둔 기록과 같다.

      예문

      • 평가자마다 좋은 답의 기준이 달라 선호 데이터에서 같은 쌍의 판정이 엇갈렸다.
      • 선호 데이터를 모을 때 길이만 보고 고르지 않도록 평가 가이드를 다시 썼다.
      • DPO 학습용으로 선호 데이터 2만 쌍을 만들었다.

      헷갈리는 용어 비교

      SFT 데이터
      SFT 데이터는 정답 하나를 보여 주는 지시와 응답 쌍이고, 선호 데이터는 어느 답이 더 나은지 비교한 기록이다. 정답을 가르칠 때는 SFT, 좋고 나쁨의 취향을 가르칠 때는 선호 데이터를 쓴다.
      데이터 라벨링
      데이터 라벨링은 데이터에 정답이나 분류를 붙이는 일 전반을 뜻하고, 선호 데이터는 그중 두 응답의 우열을 붙이는 특별한 형태다.
