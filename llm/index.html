      LLM

      large language model실무

      다른 이름: 대규모 언어 모델, 거대 언어 모델, 대형 언어 모델

      뜻풀이

      쉬운 AI 사전

      1. [명사] (모델) 엄청난 양의 글을 읽고 배워서 사람처럼 글을 이해하고 쓰는 AI 모델. 챗GPT, 클로드, 제미나이 같은 서비스의 '두뇌'다.

      실무 AI 사전

      1. [명사] (모델) 수십억~수조 개의 파라미터를 가진 언어 모델. 요약, 번역, 질의응답, 코드 생성 등 다양한 과업을 하나의 모델로 처리하며, API나 오픈 가중치 형태로 쓴다.

      전문 AI 사전

      1. [명사] (모델) 대규모 텍스트 코퍼스로 다음 토큰 예측을 사전 학습한 트랜스포머 기반 신경망. 규모가 커지면 소수 예시만으로 새 과업을 수행하는 창발적 능력을 보인다.

      관용구/함께 쓰는 말

      • LLM 기반 서비스 - 대규모 언어 모델을 뒤에 두고 돌아가는 앱이나 기능.
      • 오픈 LLM - 가중치를 공개해 누구나 내려받아 쓸 수 있는 언어 모델.

      쉬운 비유

      도서관의 책을 엄청나게 많이 읽고 글의 흐름을 몸에 익힌 사람과 같다. 다음에 올 말을 잘 짐작하는 능력으로 글을 이해하고 쓴다.

      예문

      • 요즘 나오는 AI 서비스는 대부분 LLM을 기반으로 한다.
      • 사내 문서 검색에 LLM을 붙이려면 먼저 보안 검토가 필요하다.

      헷갈리는 용어 비교

      sLLM
      LLM은 파라미터가 아주 많은 큰 언어 모델이고, sLLM은 이를 작게 줄인 모델이다. sLLM은 성능 폭은 좁지만 비용이 적고 내 서버나 기기에서 돌리기 쉽다.
      챗GPT
      LLM은 모델의 종류를 가리키는 말이고, 챗GPT는 LLM을 이용해 만든 서비스 이름이다. 모델과 서비스를 구분해서 말해야 한다.
