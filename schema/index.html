      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 데이터가 어떤 항목으로 이루어지고 각 항목이 무슨 종류인지 정해 놓은 설계도.

      실무 AI 사전

      1. [명사] (데이터) 테이블의 열 이름, 자료형, 필수 여부, 관계를 정의한다. 스키마가 바뀌면 파이프라인이 깨지므로 변경 관리가 중요하다. LLM에서는 JSON 스키마로 출력 형식을 정해 구조화된 응답을 받는다.

      전문 AI 사전

      1. [명사] (데이터) 데이터의 구조와 제약을 형식적으로 기술한 명세. 관계형 DB에서는 테이블, 열, 키, 제약을, JSON에서는 JSON Schema로 필드 타입과 필수 속성을 정의한다. 스키마 진화는 데이터 파이프라인의 호환성 관리 쟁점이다.

      관용구/함께 쓰는 말

      • 스키마 변경 — 열을 추가하거나 이름이나 타입을 바꾸는 일.
      • JSON 스키마 — JSON 데이터의 형식을 정의하는 표준 방식.

      쉬운 비유

      건물 설계도와 같다. 방이 몇 개이고 어디에 문이 있는지 정하고, 그에 맞춰 짓는다.

      예문

      • 도구 호출 응답은 스키마를 정해 두면 필수 필드가 빠지지 않는다.
      • 원천 시스템이 열 이름을 바꿔서 스키마 불일치로 파이프라인이 멈췄다.
      • 테이블 스키마를 문서로 공유해 팀원이 같은 열을 같은 의미로 쓰게 했다.
