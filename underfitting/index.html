      과소적합

      underfitting실무

      다른 이름: 언더피팅, Underfitting, 과소학습

      뜻풀이

      쉬운 AI 사전

      1. [명사] (학습) 모델이 너무 단순하거나 덜 배워서, 학습 데이터에서조차 제대로 못 맞히는 상태.

      실무 AI 사전

      1. [명사] (학습) 학습 점수와 검증 점수가 둘 다 낮으면 과소적합을 의심한다. 더 복잡한 모델을 쓰거나, 피처를 늘리거나, 더 오래 학습하거나, 규제를 줄여서 해결한다.

      전문 AI 사전

      1. [명사] (학습) 모델의 표현력이 부족해 편향이 큰 상태로, 학습 오차 자체가 높다. 편향-분산 트레이드오프에서 편향 쪽 실패에 해당하며, 학습 곡선에서 학습/검증 오차가 모두 높은 수준에 머무는 것으로 진단한다.

      관용구/함께 쓰는 말

      • 학습 부족 - 에폭이 너무 적거나 학습률이 너무 낮아 모델이 충분히 배우지 못한 상태.
      • 모델 용량 - 모델이 얼마나 복잡한 패턴을 표현할 수 있는지의 크기.

      쉬운 비유

      시험공부를 하루만 하고 들어간 학생과 같다. 연습 문제도 못 풀고 실제 시험도 못 푼다.

      예문

      • 직선 하나로 곡선 모양 데이터를 맞추려니 학습 데이터에서도 오차가 컸다. 전형적인 과소적합이다.
      • 학습 점수도 검증 점수도 60점대라서 과소적합이라 보고 모델을 더 깊게 만들었다.
      • 규제를 너무 세게 걸어서 과소적합이 생겼다.

      헷갈리는 용어 비교

      과적합
      과소적합은 학습 데이터에서도 점수가 낮고, 과적합은 학습 데이터에서는 높지만 새 데이터에서 점수가 떨어진다. 해결도 반대로, 과소적합은 모델을 키우고 과적합은 규제하거나 데이터를 늘린다.
