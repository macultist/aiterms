      데이터 드리프트

      data drift실무

      다른 이름: 데이터 분포 변화, 공변량 이동, covariate shift, 입력 드리프트, 데이터 시프트

      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 시간이 지나면서 실제로 들어오는 데이터의 모습이 학습 때와 달라지는 현상.

      실무 AI 사전

      1. [명사] (데이터) 계절, 신제품, 사용자 변화 등으로 입력 분포가 달라지면 학습 때 좋았던 모델도 성능이 떨어진다. 모니터링으로 감지해 재학습 시점을 정한다. 정답과의 관계가 변하는 개념 드리프트와는 구분한다.

      전문 AI 사전

      1. [명사] (데이터) 입력 변수의 주변 분포 P(X)가 학습 시점과 운영 시점 사이에 변하는 현상(공변량 이동). KS 검정, PSI, 젠슨-섀넌 발산 등으로 측정한다. P(Y|X)가 변하면 개념 드리프트로 별도 처리한다.

      관용구/함께 쓰는 말

      • PSI - 집단 안정성 지수. 분포가 얼마나 변했는지 보는 값.
      • 모니터링 임계값 - 드리프트로 판단하는 기준선.

      쉬운 비유

      매년 같은 시험을 준비했는데 출제 경향이 서서히 바뀌어 예전 문제집이 점점 안 맞는 상황과 같다.

      예문

      • 코로나 이후 고객 구매 패턴이 달라져 데이터 드리프트로 수요 예측 정확도가 떨어졌다.
      • 입력 열의 평균이 학습 때와 크게 달라져 데이터 드리프트 경고가 울렸다.
      • 드리프트 감지 후 최근 데이터로 모델을 다시 학습시켰다.

      헷갈리는 용어 비교

      개념 드리프트
      데이터 드리프트는 입력의 분포가 변하는 것이고, 개념 드리프트는 입력과 정답의 관계가 바뀌는 것이다.
