      JSON

      javascript object notation실무

      다른 이름: 제이슨, JSON 형식

      뜻풀이

      쉬운 AI 사전

      1. [명사] (도구) 이름과 값을 짝지어 적는, 사람도 읽을 수 있고 컴퓨터도 처리하기 쉬운 데이터 모양.

      실무 AI 사전

      1. [명사] (도구) API 요청과 응답, 설정 파일, 학습 데이터 저장에 두루 쓰는 텍스트 형식. LLM에게 답을 JSON으로 달라고 하면 프로그램이 곧바로 읽을 수 있어 AI를 앱에 붙일 때 자주 쓴다. 이 사전의 데이터도 이 형식이다.

      전문 AI 사전

      1. [명사] (도구) 객체, 배열, 문자열, 숫자, 불리언, null로 이루어진 경량 데이터 교환 형식. 언어에 독립적이며 키는 문자열이어야 한다. 모델 출력이 문법에 맞는 JSON이 되도록 하는 구조화된 출력 기능이 널리 쓰인다.

      관용구/함께 쓰는 말

      • JSON 파싱 - JSON 문자열을 프로그램이 다룰 수 있는 구조로 읽어 들이는 것.
      • 키와 값 - 이름과 그 내용이 짝을 이룬 JSON의 기본 단위.

      쉬운 비유

      신청서 양식과 같다. 이름란과 나이란에 값을 적어 두면 누가 보아도 어느 칸이 무엇인지 알 수 있다.

      예문

      • API 응답이 JSON으로 와서 필요한 항목만 꺼내 썼다.
      • 모델에게 결과를 JSON 형식으로만 출력하라고 지시했다.
      • JSON 따옴표 하나가 빠져서 전체 파싱이 실패했다.

      헷갈리는 용어 비교

      API
      API는 서비스에 요청을 보내는 방법이고, JSON은 그 요청과 응답에 담아 보내는 데이터의 모양이다. 편지를 보내는 우편 체계가 API이고 편지지에 적는 양식이 JSON이다.
