      pipeline실무

      다른 이름: ML 파이프라인, 머신러닝 파이프라인, AI 파이프라인

      뜻풀이

      쉬운 AI 사전

      1. [명사] (인프라) 여러 작업을 순서대로 이어 붙여, 앞 단계의 결과가 다음 단계로 자동으로 넘어가게 만든 흐름. 공장의 컨베이어 벨트와 비슷하다.

      실무 AI 사전

      1. [명사] (인프라) 데이터 수집, 전처리, 학습, 평가, 배포처럼 반복되는 작업을 하나의 흐름으로 묶어 자동으로 돌리는 구조. 한 번 만들어 두면 같은 과정을 새 데이터로 다시 돌릴 수 있어 결과를 재현하기 쉽고, 실수로 단계를 빼먹는 일도 줄어든다.

      전문 AI 사전

      1. [명사] (인프라) 각 단계를 입력과 출력이 정해진 독립 모듈로 나누고 의존 관계를 방향 있는 그래프(DAG)로 연결한 실행 구조. 머신러닝에서는 데이터 검증, 피처 생성, 학습, 평가, 모델 등록, 배포까지를 코드로 정의해 스케줄러나 오케스트레이터가 실행한다. 전처리와 모델을 한 객체로 묶는 라이브러리 기능을 가리키기도 한다.

      관용구/함께 쓰는 말

      • 파이프라인을 태우다 - 만들어 둔 자동 처리 흐름에 작업을 올려 실행하는 것.
      • 파이프라인이 깨지다 - 중간 단계의 오류나 입력 형식 변경으로 전체 흐름이 멈추는 것.
      • 엔드 투 엔드 파이프라인 - 입력부터 최종 결과까지 한 흐름으로 이어진 처리 구조.

      쉬운 비유

      세차장의 자동 라인과 같다. 물 뿌리기, 비누칠, 헹굼, 건조가 정해진 순서로 이어지고, 차만 넣으면 사람이 일일이 손대지 않아도 끝난다.

      예문

      • 새 데이터가 들어오면 전처리부터 학습, 평가까지 파이프라인이 알아서 돌아간다.
      • 파이프라인 중간 단계에서 실패해서 어느 단계부터 다시 돌릴지 확인하고 있다.
      • 전처리를 파이프라인에 넣어 두면 학습 때와 서비스 때 같은 방식으로 데이터를 다룰 수 있다.

      헷갈리는 용어 비교

      데이터 파이프라인
      파이프라인은 데이터 이동에 한정되지 않고 학습, 평가, 배포, 심지어 코드 빌드까지 단계를 잇는 넓은 말이다. 데이터 파이프라인은 그중 데이터를 모으고 옮기고 가공하는 흐름만 가리키며, ML 파이프라인의 앞단에 놓이는 경우가 많다.
      워크플로
      워크플로는 사람의 승인 같은 업무 절차까지 포함하는 일의 흐름 전반을 뜻하고, 파이프라인은 주로 자동으로 이어지는 처리 단계를 뜻한다. 실무에서는 두 말이 섞여 쓰이지만 파이프라인 쪽이 자동 실행 느낌이 더 강하다.
