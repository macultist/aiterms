      피처 스토어

      feature store전문

      다른 이름: 특징 저장소, 피처 저장소

      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) AI가 판단할 때 쓰는 재료 값을 한곳에 정리해 두고 여러 모델이 함께 꺼내 쓰게 하는 창고.

      실무 AI 사전

      1. [명사] (데이터) 고객의 최근 구매 횟수 같은 피처를 한 번 만들어 저장해 두고, 학습할 때와 서비스할 때 똑같은 값을 쓰게 하는 저장소. 팀마다 같은 피처를 다시 만드는 낭비와 학습 때와 서비스 때 값이 달라지는 문제를 줄인다.

      전문 AI 사전

      1. [명사] (데이터) 피처 정의, 계산, 저장, 제공을 중앙화하는 시스템으로 학습용 오프라인 저장소와 저지연 서빙용 온라인 저장소로 구성된다. 시점 정합성(point-in-time correctness)을 지켜 데이터 누수를 막고 학습-서빙 불일치(skew)를 줄인다.

      관용구/함께 쓰는 말

      • 학습-서빙 불일치 - 학습 때와 실제 서비스 때 입력 값 계산이 달라지는 문제.
      • 피처 재사용 - 한 번 만든 피처를 여러 모델이 다시 쓰는 것.

      쉬운 비유

      식당 주방의 손질된 재료 보관함과 같다. 손질을 한 번만 하고 여러 요리사가 같은 재료를 가져다 쓴다.

      예문

      • 고객 이탈 모델과 추천 모델이 같은 피처 스토어에서 값을 가져온다.
      • 피처 스토어 덕분에 학습 때와 서비스 때 피처 값이 어긋나는 문제가 사라졌다.
      • 새 피처는 먼저 피처 스토어에 등록하고 쓰기로 했다.

      헷갈리는 용어 비교

      데이터 웨어하우스
      웨어하우스는 분석용 원천 데이터를 모으는 곳이고, 피처 스토어는 그 데이터에서 만든 모델 입력 값을 학습과 서비스에 빠르게 제공하는 곳이다. 피처 스토어는 실시간 조회와 시점 정합성에 더 신경 쓴다.
