      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 데이터가 필요한 곳으로 깨끗하게 흘러가도록 길을 만드는 직업.

      실무 AI 사전

      1. [명사] (데이터) 여러 시스템의 데이터를 모아 저장하고 정리하는 파이프라인을 만들어 운영한다. 분석가와 AI 모델이 믿고 쓸 데이터가 항상 준비되도록 하는 것이 목표다.

      전문 AI 사전

      1. [명사] (데이터) 데이터 수집, ETL/ELT, 웨어하우스와 레이크 설계, 스케줄링, 품질 점검, 비용과 성능 최적화를 맡는 직무다. SQL, 분산 처리, 클라우드 인프라 역량이 필요하다.

      관용구/함께 쓰는 말

      • 데이터 엔지니어링 — 데이터를 수집, 저장, 가공하는 체계를 만드는 일.
      • 데이터 인프라 — 데이터가 모이고 흐르는 기반 시스템.

      쉬운 비유

      수도관을 놓고 정수 시설을 관리하는 사람과 같다. 물(데이터)이 깨끗하게 각 가정에 닿도록 한다.

      예문

      • 데이터 엔지니어가 매일 새벽 매출 데이터를 모으는 파이프라인을 고쳤다.
      • 모델이 이상하다고 했더니 데이터 엔지니어가 어제 들어온 로그가 누락됐다고 찾아냈다.
      • 데이터 엔지니어가 없으면 분석가가 시간의 절반을 데이터 정리에 쓴다.

      헷갈리는 용어 비교

      데이터 사이언티스트
      엔지니어는 데이터가 제때 정확히 오도록 시스템을 만들고, 사이언티스트는 그 데이터로 분석과 모델링을 한다. 한 사람이 둘을 겸하는 작은 팀도 많다.
      ML 엔지니어
      데이터 엔지니어의 일은 데이터의 흐름이고 ML 엔지니어의 일은 모델의 배포와 운영이다.
