      실무 AI 사전

      1. 「명사」 『에이전트』 컨텍스트 윈도 밖의 정보를 저장·검색해 대화 간 연속성을 주는 구조. 요약 저장, 벡터 검색, 파일 기반 메모리 등으로 구현하며 에이전트의 핵심 요소다.

      쉬운 비유

      단골 카페 사장님이 내가 늘 마시는 메뉴를 기억해 두었다가 다음에 먼저 물어보는 것과 같다. 대화가 끝나도 중요한 정보를 따로 적어 둔다.

      예문

      • 메모리 기능 덕분에 매번 내 상황을 다시 설명하지 않아도 된다.
      • 메모리에 내 직무와 말투 선호를 저장해 두었더니 새 대화에서도 설명 없이 같은 형식으로 답해 준다.

      헷갈리는 용어 비교

      컨텍스트 윈도
      컨텍스트 윈도는 AI가 한 번에 볼 수 있는 대화의 범위로, 대화가 끝나거나 넘치면 사라진다. 메모리는 그 바깥에 정보를 저장해 두었다가 다음 대화에 다시 불러오는 장치다.
      RAG
      RAG는 주로 회사 문서처럼 외부 자료를 검색해서 답에 붙이는 기술이고, 메모리는 사용자와의 대화에서 얻은 취향과 맥락을 저장하는 기능이다. 구현에 비슷한 검색 기술을 쓸 수는 있지만 저장하는 내용이 다르다.
