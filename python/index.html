      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『코딩』 문법이 쉬워서 입문자가 많이 배우는 프로그래밍 언어. AI 개발에서 가장 널리 쓰인다.

      실무 AI 사전

      1. 「명사」 『코딩』 데이터 분석, 모델 학습, API 서버, 자동화 스크립트까지 한 언어로 할 수 있고 AI 라이브러리가 가장 풍부하다. 연산이 무거운 부분은 C++이나 CUDA로 된 라이브러리가 맡고 파이썬은 이를 조립하는 역할을 한다.

      전문 AI 사전

      1. 「명사」 『코딩』 동적 타입의 인터프리터 방식 범용 언어. 간결한 문법과 방대한 생태계로 머신러닝 연구와 운영의 사실상 표준이 되었으며, 속도가 느린 점은 NumPy, PyTorch 같은 네이티브 확장 라이브러리로 보완한다.

      관용구/함께 쓰는 말

      • 파이썬스럽다 — 파이썬 커뮤니티에서 간결하고 관용적인 코드 스타일을 가리키는 말.
      • 가상환경 — 프로젝트마다 라이브러리 버전을 따로 쓰도록 분리한 환경.

      쉬운 비유

      외국어로 치면 영어 같은 위치다. 배우기 쉽고 거의 모든 AI 도구가 이 언어로 먼저 나온다.

      예문

      • AI 공부를 시작하려고 파이썬 기초 강의부터 들었다.
      • 모델 학습 코드는 대부분 파이썬으로 짜여 있다.
      • 파이썬 버전이 달라서 라이브러리 설치가 안 된다.

      헷갈리는 용어 비교

      주피터 노트북
      파이썬은 언어이고 주피터 노트북은 그 언어를 한 칸씩 돌려 보는 실습 도구다. 파이썬을 쓸 때 노트북 없이 파일로 실행하는 경우도 많다.
