      sLLM

      small large language model실무

      다른 이름 · 소형 언어 모델, 경량 언어 모델, SLM

      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『모델』 덩치를 줄인 언어 모델. 성능은 조금 낮지만 비용이 싸고 회사 서버나 스마트폰 안에서도 돌릴 수 있다.

      실무 AI 사전

      1. 「명사」 『모델』 파라미터 수가 수억~수십억 수준으로 작아 온프레미스·온디바이스 배포가 가능한 언어 모델. 특정 업무에 맞춰 파인튜닝해 쓰는 경우가 많다.

      쉬운 비유

      대형 트럭 대신 소형 배달 오토바이를 쓰는 것과 비슷하다. 많이 싣지는 못해도 좁은 길을 싸고 빠르게 다닐 수 있다.

      예문

      • 보안 때문에 외부 API 대신 사내 서버에 sLLM을 올렸다.
      • 고객 문의 분류만 하면 되니 큰 모델보다 sLLM이 더 알맞다.

      헷갈리는 용어 비교

      LLM
      sLLM은 LLM보다 파라미터 수가 작아 가볍고 싸지만, 어려운 문제에서는 큰 모델보다 못한 경우가 많다. 특정 업무 하나에 맞춰 쓸 때 효율이 좋다.
      온디바이스 AI
      sLLM은 모델의 크기에 관한 말이고, 온디바이스 AI는 AI가 기기 안에서 돌아간다는 실행 위치에 관한 말이다. 작은 sLLM이어야 스마트폰 같은 기기에서 돌리기 쉬워 둘이 자주 함께 나온다.
