      뜻풀이

      쉬운 AI 사전

      1. [명사] (도구) 프로그램이 서비스에 요청을 보낼 때 찾아가는 주소.

      실무 AI 사전

      1. [명사] (도구) AI 모델을 서비스할 때 요청을 받는 주소 하나하나를 뜻하며, 보통 URL 형태다. 텍스트 생성, 임베딩, 이미지 생성처럼 기능마다 엔드포인트가 따로 있고 인증 키와 함께 호출한다.

      전문 AI 사전

      1. [명사] (도구) 클라이언트가 HTTP 요청으로 접근하는 서버 측 자원의 URL 경로와 메서드의 조합. 요청 형식, 응답 스키마, 인증 방식이 정의되며 버전이 경로에 포함되는 경우가 많다.

      관용구/함께 쓰는 말

      • 엔드포인트 호출 - 해당 주소로 요청을 보내 기능을 실행하는 것.
      • 404 오류 - 요청한 주소에 자원이 없다는 응답.

      쉬운 비유

      가게의 창구 번호와 같다. 환전은 3번, 입금은 5번 창구로 가듯 기능마다 갈 곳이 정해져 있다.

      예문

      • 이 엔드포인트로 질문을 보내면 모델의 답이 JSON으로 돌아온다.
      • 엔드포인트 주소를 잘못 적어서 404 오류가 났다.
      • 모델을 배포하면 자동으로 호출용 엔드포인트가 생긴다.

      헷갈리는 용어 비교

      API
      API는 서비스가 제공하는 기능 전체와 사용 규칙을 가리키고, 엔드포인트는 그중 개별 기능에 접근하는 구체적인 주소다. API 안에 엔드포인트가 여러 개 들어 있다.
