      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 공부하는 중간에 실력을 점검하려고 따로 떼어 둔 연습 시험 문제.

      실무 AI 사전

      1. [명사] (데이터) 학습 중에 모델이 새 데이터에서 얼마나 잘하는지 보고, 하이퍼파라미터를 정하거나 조기 종료 시점을 고를 때 쓴다. 학습에는 쓰지 않는다.

      전문 AI 사전

      1. [명사] (데이터) 학습 집합과 분리한 표본으로, 모델 선택과 하이퍼파라미터 조정, 조기 종료 판단에 쓰이는 일반화 오차의 추정치를 준다. 검증 점수로 반복해서 튜닝하면 검증 데이터에 과적합될 수 있어 최종 평가는 별도의 테스트 데이터로 한다.

      관용구/함께 쓰는 말

      • 검증 손실 - 검증 데이터에서 계산한 손실 값.
      • 홀드아웃 - 일부를 떼어 두고 학습에 쓰지 않는 방식.

      쉬운 비유

      본시험 전에 보는 모의고사와 같다. 모의고사 결과를 보고 공부 방법을 고치지만, 본시험 문제는 미리 보지 않는다.

      예문

      • 검증 데이터 손실이 오르기 시작해서 학습을 멈췄다.
      • 학습, 검증, 테스트를 8:1:1로 나눴다.
      • 검증 데이터로 하이퍼파라미터를 너무 많이 바꾸면 검증에도 맞춰 버린다.

      헷갈리는 용어 비교

      테스트 데이터
      검증 데이터는 학습 중 모델을 고르고 조정하는 데 계속 쓰고, 테스트 데이터는 끝난 뒤 최종 성능을 한 번 확인하는 데 쓴다.
