      실무 AI 사전

      1. 「명사」 『서비스』 코드베이스 탐색, 수정, 테스트, 깃 작업을 자율 수행하는 에이전트형 코딩 도구. CLI, 데스크톱 앱, IDE 확장으로 제공되며 MCP로 외부 도구를 연결한다.

      쉬운 비유

      프로젝트 폴더에 상주하는 보조 개발자와 같다. 채팅으로 요청하면 파일을 열어 읽고, 고치고, 실행해 결과까지 보고한다.

      예문

      • 클로드 코드로 이 사전 웹사이트를 만들고 있다.
      • 클로드 코드에게 테스트를 돌려 실패한 부분을 고치게 했다.

      헷갈리는 용어 비교

      클로드
      클로드는 앤스로픽의 AI 모델과 대화 서비스를 가리키고, 클로드 코드는 그 모델로 프로젝트 파일을 직접 다루게 만든 코딩 도구다. 같은 모델이라도 도구가 붙으면 하는 일이 달라진다.
      코파일럿
      깃허브 코파일럿도 코딩을 돕는 도구지만 제공 회사와 제품이 다르다. 클로드 코드는 앤스로픽이 만든 별개 제품이므로 이름이 비슷하다고 같은 도구로 보면 안 된다.
