      웹훅

      webhook실무

      다른 이름: Webhook, 웹 훅, 웹후크

      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『도구』 어떤 일이 생기면 서비스가 미리 알려 준 주소로 알림 메시지를 자동으로 보내 주는 방식.

      실무 AI 사전

      1. 「명사」 『도구』 AI 작업이 끝났을 때나 결제가 완료됐을 때처럼 사건이 생기면 서버가 내 주소로 HTTP 요청을 보내 준다. 오래 걸리는 이미지 생성이나 영상 변환 작업의 결과를 계속 확인하지 않고 완료 신호를 받을 수 있어 자동화 도구에서 자주 쓴다.

      전문 AI 사전

      1. 「명사」 『도구』 이벤트가 발생하면 서버가 구독자가 등록한 URL로 HTTP POST를 보내는 이벤트 기반 콜백 방식. 서명 검증으로 위조 요청을 막고, 수신 실패에 대비한 재전송과 멱등한 처리가 필요하다. 클라이언트가 주기적으로 묻는 폴링과 대비된다.

      관용구/함께 쓰는 말

      • 웹훅을 걸다 — 사건 발생 시 알림이 오도록 주소를 등록하는 것.
      • 서명 검증 — 받은 요청이 믿을 만한 곳에서 온 것인지 확인하는 절차.

      쉬운 비유

      택배가 도착하면 문자를 보내 달라고 부탁해 두는 것과 같다. 계속 물어보는 대신 소식이 오기를 기다린다.

      예문

      • 영상 생성이 끝나면 웹훅으로 알려 주도록 설정해 두었다.
      • 웹훅 주소를 등록하면 새 주문이 들어올 때마다 알림이 온다.
      • 웹훅 요청이 위조되지 않았는지 서명을 확인한다.

      헷갈리는 용어 비교

      API
      보통 API는 내가 서비스에 요청을 보내 답을 받아 오는 방식이고, 웹훅은 서비스가 사건이 생기면 먼저 내게 연락하는 방식이다. 내가 계속 묻는 것과 소식이 오기를 기다리는 것의 차이다.
