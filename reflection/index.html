      리플렉션

      reflection전문

      다른 이름: 자기 반성, 자기 성찰, reflexion, 셀프 리플렉션, self-reflection

      뜻풀이

      쉬운 AI 사전

      1. [명사] (에이전트) AI가 자기 답을 다시 읽어 보고 틀린 곳을 스스로 찾아 고치는 과정.

      실무 AI 사전

      1. [명사] (에이전트) 첫 답을 쓴 뒤 '문제가 없는지 검토해'라는 단계를 두면 오류나 누락을 줄일 수 있다. 코드를 짜고 테스트 결과를 본 뒤 고치는 에이전트 루프에서 흔히 쓴다.

      전문 AI 사전

      1. [명사] (에이전트) 모델이 자신의 출력이나 행동 결과를 평가하는 피드백을 생성하고, 그 피드백을 다음 시도에 반영하는 패턴. Reflexion 같은 방법은 시도마다 생긴 언어적 반성을 기억 버퍼에 쌓아 두고 재시도 때 참고한다. 외부 신호 없이는 자기 오류를 못 찾을 수 있다는 한계가 알려져 있다.

      관용구/함께 쓰는 말

      • 자기 검토 - 생성한 답을 스스로 다시 점검하는 일.
      • 재시도 루프 - 실패를 보고 고쳐 다시 시도하는 반복 구조.

      쉬운 비유

      시험을 끝낸 뒤 답안지를 처음부터 다시 읽으며 실수를 찾아 고치는 검토 시간과 같다.

      예문

      • 코드 에이전트가 테스트 실패 로그를 읽고 리플렉션 단계에서 원인을 적은 뒤 고쳐 다시 실행했다.
      • 리플렉션 단계를 넣었더니 보고서의 숫자 불일치를 스스로 잡아냈다.
      • 답이 틀렸다고 믿지 않으면 리플렉션도 같은 오류를 그대로 인정하는 경우가 있다.

      헷갈리는 용어 비교

      ReAct
      ReAct는 생각과 행동을 번갈아 하며 외부 정보를 모으는 패턴이고, 리플렉션은 이미 나온 결과를 돌아보고 고치는 패턴이다. 둘을 함께 쓰는 에이전트가 많다.
      LLM 심판
      LLM 심판은 평가를 목적으로 별도 모델이 결과에 점수를 매기는 일이고, 리플렉션은 같은 모델이 자기 결과를 고쳐 쓰기 위해 점검하는 일이다.
