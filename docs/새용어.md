# 새 AI 용어 찾기 절차 (주 1회)

방식: 이 창이 후보를 찾아옴 → 사장님이 고르심 → 이 창이 뜻풀이를 쓰고 사장님 승인 뒤 배포.

## 1. 찾기 (이 창)
- 범위: 지난 7일 동안의
  - 국내외 AI 뉴스(AI타임스·전자신문·TechCrunch·The Verge 등)
  - 블로그
  - 주요 회사 발표(OpenAI·Anthropic·Google·Meta·Microsoft·네이버·카카오·삼성)
  - 검색 추세(Google Trends·네이버 데이터랩)
- 후보 기준(모두 맞아야 함)
  1. 사전에 아직 없음. 표제어·영문·별칭 모두와 대조한다. 대조 목록은 아래 명령으로 뽑는다.
     `node -e "global.window={};require('./data/terms.js');console.log(window.TERMS.map(t=>[t.term,t.en,...(t.alias||[])].join('|')).join('\n'))"`
  2. 한 회사 제품 이름이 아니라 여러 곳에서 쓰는 말이다. 출처는 서로 다른 곳 2개 이상이어야 한다.
  3. 한국어 사용자가 검색해 볼 만한 말이다.
- 개수: 5~10개.

## 2. 후보 목록 (이 창)
- 파일: `docs/후보/YYYY-MM-DD.md`
- 후보마다 아래를 적는다.
  - 한 줄 뜻
  - 출처 링크 2개
  - 처음 보인 시기
  - 추천 난이도(일상·실무·전문)
  - 추천 이유
- 모음 블로그·AI 요약 뉴스레터만 있는 출처는 "확인 필요"로 표시한다. 출처가 1개뿐인 후보는 "보류"로 표시한다.
- 사장님께 이 창에서 목록을 보여 드리고 고르시게 한다.

## 3. 쓰기·점검 (사장님이 고른 것만)
- `data/terms.js` 에 지금 품질 기준으로 쓴다.
  - 뜻풀이
  - 쉬운 비유(like)
  - 예문 2개 이상(ex)
  - 헷갈리는 용어 비교(vs)
  - 관련어(rel)
  - 표기법(note)
  - 확인일(checked)
- 아래 두 명령을 돌린다.
  - `node build.js` (페이지·sitemap 다시 만들기)
  - `node check.js` (`check ok` 가 나와야 함)
- 미리보기 http://localhost:8790 에서 새 용어 페이지를 확인한다. 390px에서 가로 넘침이 없는지도 본다.

## 4. 배포
- 사장님이 이 창에서 승인하신 뒤에만 `git push` 한다. main 에 푸시하면 1~2분 뒤 https://macultist.kr/aiterms/ 에 반영된다.
- 팀장실에 보고한다(무엇을·커밋·라이브 주소·확인 결과·미해결).

## 정기 예약
- 매주 정해진 시각에 1번 단계를 자동으로 시작하는 예약은 사장님이 이 창에서 직접 승인하셔야만 건다. 팀장실이 전한 지시로는 걸지 않는다.
- 상태: 10-14 사장님 이 창 승인으로 설정. 매주 토 09:00 앱 예약 작업 `aiterms-weekly-new-terms` (~/.claude/scheduled-tasks/). 후보 찾기와 목록 작성까지만 하고 이 창에 알림. 용어 추가와 배포는 안 함.
