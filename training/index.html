      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『학습』 AI에게 많은 데이터를 보여 주어 규칙을 익히게 하는 과정. 사람이 공부하는 것에 빗댄 말이다.

      실무 AI 사전

      1. 「명사」 『학습』 손실 함수가 작아지도록 모델 파라미터를 반복 갱신하는 과정. 사전 학습, 파인튜닝, 강화 학습 단계로 나뉘며 데이터와 GPU 비용이 핵심 변수다.

      관용구/함께 쓰는 말

      • 학습 데이터 — 모델을 학습시키는 데 쓰는 데이터 묶음.
      • 학습 종료 시점 — 모델이 학습한 데이터의 마지막 날짜. 그 뒤의 일은 모른다.

      쉬운 비유

      문제집을 반복해서 풀며 틀린 만큼 풀이 방법을 고치는 공부와 같다. AI는 정답과의 차이를 줄이는 방향으로 내부 숫자를 조금씩 바꾼다.

      예문

      • 이 모델은 2025년까지의 데이터로 학습했다.
      • 이번 모델은 학습에 쓴 데이터의 저작권 문제로 논란이 있었다.

      헷갈리는 용어 비교

      추론
      학습은 데이터를 보며 모델을 만드는 단계이고, 추론은 완성된 모델이 실제 질문에 답하는 단계다. 학습에는 큰 비용이 한 번 들고, 추론은 쓸 때마다 비용이 든다.
      파인튜닝
      학습은 모델을 처음부터 만드는 과정까지 포함하는 넓은 말이고, 파인튜닝은 이미 학습된 모델을 특정 목적에 맞게 추가로 학습시키는 일이다.
