      쉬운 AI 사전

      1. [명사] (데이터) 데이터를 그때그때 처리하지 않고 모아 두었다가 한꺼번에 처리하는 방식.

      실무 AI 사전

      1. [명사] (데이터) 하루치나 한 시간치 데이터를 모아 정해진 시각에 일괄로 돌리는 처리. 매일 밤 학습 데이터를 만들거나 추천 결과를 미리 계산해 두는 일에 쓰이며, 실시간성은 떨어지지만 많은 양을 안정적이고 저렴하게 처리한다.

      전문 AI 사전

      1. [명사] (데이터) 유한한 입력 집합을 한 번에 읽어 처리하고 결과를 내는 방식. 처리량 최적화에 유리하며 실패 시 같은 입력으로 재실행하기 쉽다. 모델 추론에서는 요청 여러 개를 묶어 GPU 효율을 높이는 배치 추론도 같은 원리다.

      관용구/함께 쓰는 말

      • 배치를 돌리다 - 모아 둔 작업을 한 번에 실행하는 것.
      • 야간 배치 - 사용자가 적은 밤 시간에 실행하는 일괄 작업.

      쉬운 비유

      빨래를 매번 한 벌씩 돌리지 않고 모아 두었다가 주말에 한 번에 돌리는 것과 같다.

      예문

      • 추천 목록은 매일 새벽 배치 처리로 미리 계산해 둔다.
      • 배치가 새벽 3시에 돌아서 아침까지는 어제 데이터가 보인다.
      • 이미지 수만 장의 분류는 실시간이 필요 없으니 배치 처리로 돌렸다.

      헷갈리는 용어 비교

      스트림 처리
      배치는 모아서 한꺼번에, 스트림은 들어오는 즉시 하나씩 처리한다. 배치는 대량 처리와 비용에 유리하고 스트림은 지연이 짧아야 하는 상황에 맞는다.
