      멀티 에이전트

      multi-agent system실무

      다른 이름: 멀티 에이전트 시스템, 다중 에이전트, multi agent, 다중 에이전트 시스템, MAS

      뜻풀이

      쉬운 AI 사전

      1. [명사] (에이전트) AI 에이전트 여러 개가 각자 맡은 역할로 협력하거나 토론하면서 한 가지 일을 해내는 구조.

      실무 AI 사전

      1. [명사] (에이전트) 기획자, 개발자, 검토자 역할을 나눠 서로 결과를 넘기거나 비평하게 한다. 일을 병렬로 나누고 전문화할 수 있지만 호출이 늘어 비용과 오류 전파를 관리해야 한다.

      전문 AI 사전

      1. [명사] (에이전트) 독립적 컨텍스트와 도구, 역할을 가진 복수의 LLM 에이전트가 메시지를 교환하며 과제를 분담하는 시스템. 오케스트레이터가 하위 에이전트에 위임하는 계층형, 동료끼리 토론하는 구조 등이 있다. 조율 비용과 컨텍스트 분리가 설계의 핵심 변수다.

      관용구/함께 쓰는 말

      • 오케스트레이터 - 여러 에이전트에게 일을 나눠 주고 결과를 모으는 조율자.
      • 에이전트 간 통신 - 에이전트끼리 메시지를 주고받는 일.

      쉬운 비유

      회사에서 기획, 개발, 검수가 팀을 이루어 한 제품을 만드는 것과 같다. 각자 전문이지만 소통이 어긋나면 일이 꼬인다.

      예문

      • 리서치 에이전트가 자료를 모으고 작성 에이전트가 초안을 쓰고 검토 에이전트가 오류를 짚는 멀티 에이전트로 만들었다.
      • 에이전트를 늘릴수록 항상 좋아지는 건 아니라서 단일 에이전트와 성능을 비교해 보았다.
      • 멀티 에이전트는 각 에이전트가 따로 컨텍스트를 가지므로 한 에이전트의 컨텍스트가 길어지는 문제를 줄인다.

      헷갈리는 용어 비교

      에이전트
      단일 에이전트는 한 모델이 스스로 계획하고 도구를 써서 일하며, 멀티 에이전트는 역할이 다른 여러 에이전트가 협력한다. 일이 복잡하고 분업이 가능할 때 멀티 에이전트를 고려한다.
      에이전트 워크플로
      에이전트 워크플로는 정해진 흐름 속에 모델 호출을 배치하는 설계 전반을 말하고, 멀티 에이전트는 그 흐름 안에서 여러 에이전트가 참여하는 구성이다.
