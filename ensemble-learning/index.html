      앙상블

      ensemble learning실무

      다른 이름: 앙상블 학습, 앙상블 기법, 앙상블 모델, ensemble

      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『모델』 여러 모델의 답을 모아서 더 믿을 만한 답을 만드는 방법. 한 사람보다 여럿의 의견을 합치면 덜 틀린다는 생각이다.

      실무 AI 사전

      1. 「명사」 『모델』 대회나 실무에서 점수를 한 단계 더 올리고 싶을 때 쓴다. 서로 다른 종류의 모델을 섞을수록 효과가 좋지만, 배포할 모델이 늘어 서빙 비용과 유지 부담이 커진다.

      전문 AI 사전

      1. 「명사」 『모델』 개별 학습기를 결합해 일반화 오차를 줄이는 방법의 총칭이다. 분산을 줄이는 배깅, 편향을 줄이는 부스팅, 학습기 출력을 메타 모델에 넣는 스태킹, 단순 평균이나 투표 방식이 있다. 개별 모델의 오류가 서로 덜 겹칠수록 이득이 크다.

      관용구/함께 쓰는 말

      • 앙상블 투표 — 여러 모델의 예측 중 다수가 고른 답을 최종 답으로 삼는 것.
      • 스태킹 — 여러 모델의 예측값을 입력으로 받는 또 다른 모델을 따로 학습시키는 방식.

      쉬운 비유

      혼자 부르는 노래보다 합창이 음정이 덜 흔들리는 것과 같다. 각자 조금씩 틀려도 목소리를 합치면 틀린 부분이 묻힌다.

      예문

      • 세 가지 모델의 예측 평균을 내는 앙상블만으로 검증 점수가 1점 가까이 올랐다.
      • 앙상블은 점수는 좋은데, 모델 다섯 개를 서버에 올리려니 응답 시간이 걱정이다.
      • 같은 모델을 시드만 바꿔 여러 번 학습해서 앙상블했다.

      헷갈리는 용어 비교

      배깅
      앙상블은 여러 모델을 합치는 방법 전체를 부르는 말이고, 배깅은 그 안의 한 방식으로 데이터를 무작위로 뽑아 모델을 독립적으로 만든 뒤 합친다.
