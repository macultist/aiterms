      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 실제로 모은 것이 아니라 컴퓨터가 만들어 낸 데이터. 실제처럼 보이지만 진짜 사람이나 사건의 기록이 아니다.

      실무 AI 사전

      1. [명사] (데이터) 개인정보 때문에 쓰기 어렵거나 구하기 힘든 데이터(희귀 사고, 의료)를 대신하는 용도로 쓴다. 시뮬레이터나 생성 모델로 만들며, LLM이 만든 문장으로 다른 모델을 학습하는 일도 흔하다. 실제 분포와 얼마나 가까운지가 관건이다.

      전문 AI 사전

      1. [명사] (데이터) 통계 모델, 시뮬레이션, 생성 모델(GAN, 확산 모델, LLM)로 생성한 데이터. 프라이버시 보호, 클래스 보강, 라벨 비용 절감에 쓰인다. 생성 모델의 결과로 다시 학습하는 일이 반복되면 분포가 좁아지는 모델 붕괴 위험이 보고된다.

      관용구/함께 쓰는 말

      • 시뮬레이션 데이터 - 가상 환경에서 만들어 낸 데이터.
      • 모델 붕괴 - AI가 만든 데이터로 반복 학습해 다양성이 줄어드는 현상.

      쉬운 비유

      실제 시험 문제를 구하기 어려워 선생님이 비슷하게 직접 만든 모의 문제와 같다. 실제와 다르면 연습이 소용없다.

      예문

      • 희귀 질환 영상이 부족해 합성 데이터로 학습 데이터를 보강했다.
      • 자율주행은 위험한 상황을 시뮬레이터로 만든 합성 데이터에 많이 기댄다.
      • 합성 데이터의 분포가 실제와 달라서 실제 환경에서 성능이 떨어졌다.

      헷갈리는 용어 비교

      데이터 증강
      증강은 있는 데이터에 변형을 가해 늘리고, 합성 데이터는 없던 데이터를 새로 만든다. 경계가 겹치는 경우도 있다.
