      데이터 거버넌스

      data governance실무

      다른 이름: 데이터 관리 체계, 데이터 거번넌스, 데이터 거버넌스 체계

      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) 데이터를 누가 어떻게 모으고 쓰고 지킬지 정한 회사 안의 규칙과 책임 체계.

      실무 AI 사전

      1. [명사] (데이터) 데이터 품질, 접근 권한, 개인정보 보호, 보관 기간을 정리해 두어야 AI 모델에 안심하고 데이터를 쓸 수 있다. 규칙이 없으면 부서마다 숫자가 달라지고 보안 사고 위험도 커진다.

      전문 AI 사전

      1. [명사] (데이터) 데이터 정책, 표준, 소유권(data ownership), 품질 관리, 접근 통제, 규제 준수를 포괄하는 관리 체계다. AI 거버넌스의 기반으로 학습 데이터의 출처와 이용 권한 관리에 직결된다.

      관용구/함께 쓰는 말

      • 데이터 오너십 — 데이터의 책임자가 누구인지 정하는 일.
      • 데이터 정책 — 데이터 사용 규칙을 적은 문서.

      쉬운 비유

      도서관의 대출 규칙과 같다. 누가 어떤 책을 얼마나 빌릴 수 있고 훼손되면 어떻게 하는지 정해 두어야 책이 질서 있게 쓰인다.

      예문

      • 데이터 거버넌스를 세우면서 부서별 데이터 담당자를 정했다.
      • 데이터 거버넌스 없이 AI를 도입했다가 개인정보가 학습에 섞여 문제가 됐다.
      • 데이터 거버넌스 위원회가 데이터 공개 범위를 심의한다.

      헷갈리는 용어 비교

      AI 거버넌스
      데이터 거버넌스는 데이터의 관리 규칙이고 AI 거버넌스는 모델과 서비스의 위험, 책임까지 다룬다. 데이터 거버넌스가 AI 거버넌스의 바탕이다.
      데이터 품질
      품질은 데이터가 얼마나 정확하고 완전한지의 상태이고, 거버넌스는 그 품질을 유지하게 하는 책임과 절차다.
