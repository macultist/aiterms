      쉬운 AI 사전

      1. 「명사」 『학습』 한번 만든 AI를 새로운 자료로 다시 공부시켜 최신 상태로 맞추는 일.

      실무 AI 사전

      1. 「명사」 『학습』 시간이 지나 데이터 분포가 달라져 성능이 떨어진 모델을 최신 데이터로 다시 학습하는 작업. 매주 같은 주기로 하거나 모니터링 경보가 울릴 때 실행하며, 새 모델이 기존 모델보다 낫다는 검증을 거쳐 교체한다.

      전문 AI 사전

      1. 「명사」 『학습』 드리프트로 저하된 예측력을 회복하기 위해 최신 데이터를 포함해 모델을 처음부터 또는 기존 가중치에서 이어 학습하는 절차. 학습 창(윈도) 선택, 파국적 망각 완화, 챔피언-챌린저 비교, 자동 트리거 설계가 쟁점이다.

      관용구/함께 쓰는 말

      • 재학습 주기 — 모델을 다시 학습시키는 간격.
      • 챔피언 모델 — 현재 운영 중인 모델로, 새 모델과 비교 대상이 되는 것.

      쉬운 비유

      해마다 개정되는 교재로 다시 공부하는 수험생과 같다. 출제 경향이 바뀌면 옛날 공부로는 점수가 떨어진다.

      예문

      • 모델 정확도가 떨어져서 지난달 데이터까지 넣어 재학습했다.
      • 재학습은 매주 일요일 밤에 자동으로 돌도록 파이프라인에 넣었다.
      • 재학습한 모델이 오히려 점수가 낮아서 교체하지 않았다.

      헷갈리는 용어 비교

      파인튜닝
      재학습은 최신 데이터로 모델을 업데이트하는 운영 행위를 가리키고, 파인튜닝은 이미 학습된 모델을 특정 목적에 맞게 추가 학습하는 기법이다. 재학습을 파인튜닝으로 할 수도 있고 처음부터 할 수도 있다.
