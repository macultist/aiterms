      MLOps

      machine learning operations실무

      다른 이름: ML옵스, 머신러닝 운영

      뜻풀이

      쉬운 AI 사전

      1. [명사] (인프라) AI 모델을 만들어 내놓는 데서 그치지 않고, 계속 잘 돌아가도록 관리하는 일과 그 체계.

      실무 AI 사전

      1. [명사] (인프라) 데이터 준비, 학습, 배포, 모니터링, 재학습을 자동화하고 팀이 함께 관리하도록 하는 운영 방식. 노트북에서 한 번 잘 나온 모델을 실제 서비스에서 꾸준히 쓰게 만드는 것이 목적이다.

      전문 AI 사전

      1. [명사] (인프라) 소프트웨어의 DevOps 원칙을 머신러닝에 확장한 것으로, 코드뿐 아니라 데이터와 모델도 버전 관리하고 지속적 통합, 지속적 배포, 지속적 학습(CT)을 구현한다. 재현성, 추적성, 모델 성능 저하 감시가 핵심 요소다.

      관용구/함께 쓰는 말

      • MLOps 체계 - 학습부터 배포와 감시까지 이어지는 운영 구조.
      • 연구에서 운영으로 - 실험 단계의 모델을 실제 서비스에 올리는 과정.

      쉬운 비유

      요리 대회에서 한 번 맛있는 음식을 만드는 것이 연구라면, 식당에서 매일 같은 맛을 안정적으로 내는 주방 시스템이 MLOps다.

      예문

      • 모델을 만드는 것보다 MLOps 체계를 갖추는 게 더 오래 걸렸다.
      • MLOps 덕분에 새 데이터로 모델이 매주 자동으로 다시 학습된다.
      • 우리 팀은 MLOps가 없어서 모델을 올릴 때마다 사람이 수동으로 작업한다.

      헷갈리는 용어 비교

      LLMOps
      MLOps는 모델을 직접 학습시키는 전통적 머신러닝 운영이 중심이고, LLMOps는 이미 만들어진 대형 언어 모델을 프롬프트, 검색, 평가 중심으로 운영하는 데 초점을 둔다.
