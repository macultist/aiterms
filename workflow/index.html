      실무 AI 사전

      1. [명사] (도구) 자료 수집, 초안 작성, 검토, 승인처럼 일이 진행되는 순서를 정리한 것. AI를 업무에 넣을 때는 어느 단계를 AI가 맡고 어느 단계에서 사람이 확인할지 워크플로로 먼저 그려 보면 도입 위치가 분명해진다.

      전문 AI 사전

      1. [명사] (도구) 작업, 조건 분기, 반복, 의존 관계로 정의된 실행 절차. 자동화 도구에서는 트리거, 액션, 조건 노드로 구성되며, LLM 앱에서는 모델 호출과 도구 사용을 정해진 순서로 잇는 고정 흐름을 뜻해 모델이 스스로 경로를 정하는 에이전트와 구분된다.

      관용구/함께 쓰는 말

      • 워크플로를 설계하다 - 일의 단계와 순서를 짜는 것.
      • 사람 승인 단계 - 자동 흐름 중간에 사람이 확인하고 넘기는 단계.

      쉬운 비유

      요리 레시피의 조리 순서와 같다. 재료 손질, 볶기, 간 맞추기가 어떤 차례로 이어지는지 적어 둔 것이다.

      예문

      • 보고서 작성 워크플로에서 초안만 AI에게 맡기고 검토는 사람이 한다.
      • 워크플로를 그려 놓고 보니 AI가 들어갈 자리가 세 군데 보였다.
      • 승인 단계 앞에 AI 검수 워크플로를 추가했다.
