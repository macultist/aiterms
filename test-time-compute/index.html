      다른 이름: 추론 시 연산, 테스트 타임 컴퓨트

      뜻풀이

      쉬운 AI 사전

      1. [명사] (모델) AI가 답할 때 더 오래 '생각'하게 해서 성능을 높이는 방법. 추론 모델이 이 원리를 쓴다.

      전문 AI 사전

      1. [명사] (모델) 추론 단계에서 더 많은 토큰 생성, 탐색, 검증을 수행해 정확도를 높이는 접근. 사고 연쇄, 자기 일관성, 트리 탐색 등이 해당하며 학습 스케일링의 대안으로 부상했다.

      쉬운 비유

      시험 시간을 넉넉히 주면 어려운 문제를 검산하며 더 정확히 푸는 것과 같다. AI도 답하기 전에 더 오래 계산하게 하면 정답률이 오른다.

      예문

      • 테스트 타임 연산을 늘리면 수학 문제 정답률이 올라간다.
      • 같은 모델이라도 테스트 타임 연산을 늘리는 설정을 켜면 응답은 느려지지만 복잡한 코딩 문제의 정답률이 높아진다.

      헷갈리는 용어 비교

      스케일링 법칙
      스케일링 법칙은 학습 때 모델과 데이터를 키우는 쪽의 규칙이고, 테스트 타임 연산은 답하는 순간에 쓰는 계산량을 늘리는 쪽이다. 둘 다 계산을 더 쓰면 성능이 오른다는 점은 같지만 쓰는 시점이 다르다.
      추론 모델
      추론 모델은 답하기 전에 길게 생각하도록 만들어진 모델이고, 테스트 타임 연산은 그 바탕에 있는 원리다. 추론 모델은 이 원리를 활용한 대표적 결과물이다.
