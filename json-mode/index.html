      뜻풀이

      쉬운 AI 사전

      1. [명사] (프롬프트) AI의 답이 항상 JSON이라는 컴퓨터가 읽기 쉬운 글 형식이 되도록 켜는 옵션.

      실무 AI 사전

      1. [명사] (프롬프트) 옵션을 켜면 모델이 문법에 맞는 JSON만 내놓는다. 다만 어떤 키를 쓸지는 프롬프트에서 따로 알려 줘야 하고, 키 이름이나 값이 기대와 다를 수 있어 코드에서 검증이 필요하다.

      전문 AI 사전

      1. [명사] (프롬프트) 생성 토큰을 JSON 문법에 맞게 제약하거나 그렇게 튜닝된 동작. 문법적 유효성은 보장하지만 특정 스키마 준수는 보장하지 않는 것이 일반적이다. 길이 한도에서 잘리면 불완전한 JSON이 나올 수 있다.

      관용구/함께 쓰는 말

      • JSON 모드 켜기 - API에서 JSON 출력 옵션을 활성화하는 일.
      • JSON 파싱 오류 - 출력이 JSON 문법에 안 맞아 프로그램이 읽지 못하는 문제.

      쉬운 비유

      '답은 꼭 편지 봉투에 넣어서 주세요'라는 규칙과 같다. 봉투 모양은 지켜지지만, 안에 무슨 내용이 들었는지는 따로 확인해야 한다.

      예문

      • JSON 모드를 켜고도 프롬프트에 필요한 키를 적어 주지 않았더니 모델이 제멋대로 키를 만들었다.
      • 답변이 JSON으로만 나오니 앞뒤에 붙던 '네, 알겠습니다' 같은 말을 정규식으로 지울 일이 없어졌다.
      • JSON 모드에서는 max tokens가 너무 작으면 중괄호가 닫히기 전에 잘린다.

      헷갈리는 용어 비교

      구조화된 출력
      JSON 모드는 문법이 맞는 JSON이면 통과이고, 구조화된 출력은 정해 둔 스키마까지 맞춘다. 업체에 따라 JSON 모드를 구조화된 출력의 한 단계 약한 버전으로 둔다.
      프롬프트로 형식 부탁
      프롬프트로 'JSON으로 답해 줘'라고만 쓰면 어쩌다 형식이 깨질 수 있다. JSON 모드는 이를 모델 쪽 제약으로 줄여 준다.
