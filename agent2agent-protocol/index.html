      A2A 프로토콜

      Agent2Agent protocol전문

      다른 이름: A2A, 에이투에이, Agent-to-Agent 프로토콜, 에이전트 간 통신 규약, Agent2Agent, 에이투에이 프로토콜

      뜻풀이

      쉬운 AI 사전

      1. [명사] (에이전트) 서로 다른 회사나 시스템에서 만든 AI 에이전트들이 말을 주고받도록 정한 공통 약속.

      실무 AI 사전

      1. [명사] (에이전트) 에이전트마다 다른 프레임워크로 만들어도 같은 규약으로 능력을 소개하고 작업을 맡기고 결과를 받을 수 있게 한다. 도구와 연결하는 MCP와 달리 에이전트끼리의 협업을 다룬다.

      전문 AI 사전

      1. [명사] (에이전트) 독립적으로 개발된 에이전트가 능력 카드로 서로를 발견하고, 작업을 위임하며 상태와 결과를 주고받도록 정의한 개방형 통신 프로토콜. HTTP, JSON 기반 메시지를 쓰며 에이전트 내부 구현을 공개하지 않고 상호작용하게 하는 데 초점을 둔다.

      관용구/함께 쓰는 말

      • 에이전트 카드 - 에이전트가 자신의 능력과 접속 방법을 소개하는 설명.
      • 작업 위임 - 다른 에이전트에게 일을 맡기는 일.

      쉬운 비유

      외국 회사끼리 일할 때 공용어와 명함 양식을 정해 두면 누가 어떤 일을 할 수 있는지 서로 알고 일을 맡길 수 있는 것과 같다.

      예문

      • 서로 다른 회사의 에이전트가 A2A 프로토콜로 일정 조율 작업을 주고받는 시연을 보았다.
      • MCP는 에이전트와 도구를, A2A 프로토콜은 에이전트와 에이전트를 잇는다고 정리했다.
      • A2A를 쓰면 에이전트 내부 구현을 몰라도 능력 설명만 보고 일을 맡길 수 있다.

      헷갈리는 용어 비교

      MCP
      MCP는 AI 모델이 외부 도구나 데이터에 연결되는 방식을 정한 규약이고, A2A 프로토콜은 에이전트가 다른 에이전트와 협업하는 방식을 정한다. 둘은 서로 대체하지 않고 함께 쓸 수 있다.
      API
      일반 API는 호출할 함수와 인자를 정확히 맞춰야 하지만, A2A는 에이전트가 작업을 말로 설명하고 결과를 상태와 함께 받는 협업에 맞춰져 있다.
