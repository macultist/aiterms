      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『학습』 큰 AI 모델 사이에 끼워 넣는 작은 추가 부품. 이 부품만 훈련해서 새 일을 가르친다.

      실무 AI 사전

      1. 「명사」 『학습』 원래 모델은 얼리고 어댑터만 학습하면 비용이 적게 든다. 업무 영역마다 어댑터를 따로 만들어 바꿔 끼우면 모델 한 벌로 여러 일을 맡길 수 있다.

      전문 AI 사전

      1. 「명사」 『학습』 트랜스포머 층 사이나 안에 삽입하는 작은 병목 구조의 모듈. 사전 학습 가중치는 고정하고 어댑터 파라미터만 학습하는 PEFT 기법이다. LoRA 가중치를 어댑터라 부르며 모델과 분리해 저장하고 교체하는 문맥도 흔하다.

      관용구/함께 쓰는 말

      • 어댑터 병합 — 학습한 어댑터를 기본 모델에 합쳐 하나로 만드는 일.
      • 어댑터 교체 — 같은 기본 모델에 다른 어댑터를 바꿔 끼우는 일.

      쉬운 비유

      전동 드릴 본체는 그대로 두고 끝에 끼우는 비트만 바꿔 다른 작업을 하는 것과 같다.

      예문

      • 법률 어댑터와 의료 어댑터를 따로 학습해 두고 질문 종류에 따라 바꿔 끼웠다.
      • 어댑터만 저장하니 기본 모델 파일을 복사하지 않아도 돼 용량이 크게 줄었다.
      • LoRA 어댑터를 기본 모델에 합쳐 하나의 모델 파일로 내보냈다.

      헷갈리는 용어 비교

      LoRA
      LoRA는 가중치 변화량을 작은 행렬 두 개로 근사해 학습하는 방식이고, 어댑터라는 말은 더 넓게 끼워 넣는 학습 모듈 전반을 가리킨다. 오늘날은 LoRA로 학습한 결과물을 어댑터라 부르는 경우가 많다.
      파인튜닝
      전체 파인튜닝은 모델의 가중치 자체를 바꾸지만, 어댑터 방식은 모델은 그대로 두고 추가 모듈만 학습한다.
