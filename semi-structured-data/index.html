      뜻풀이

      쉬운 AI 사전

      1. 「명사」 『데이터』 표처럼 완전히 딱딱하지는 않지만 이름표(태그)로 어느 정도 구조가 있는 데이터. JSON 파일이 대표적이다.

      실무 AI 사전

      1. 「명사」 『데이터』 JSON, XML, 로그 파일, 이메일 헤더 같은 형태다. 항목마다 있을 수도 없을 수도 있어 유연하지만, 분석하려면 필요한 필드를 꺼내 표로 펼치는 작업이 자주 필요하다.

      전문 AI 사전

      1. 「명사」 『데이터』 스키마가 엄격하게 강제되지 않고 태그나 키-값으로 구조를 스스로 설명하는 데이터. 계층적 중첩과 가변 필드를 허용하며 문서형 DB(MongoDB 등)나 로그 수집 시스템에서 흔히 다룬다.

      관용구/함께 쓰는 말

      • 중첩 구조 — 데이터 안에 또 데이터가 들어 있는 구조.
      • 플래트닝 — 중첩된 데이터를 평평한 표로 펼치는 일.

      쉬운 비유

      이름표가 붙어 있지만 칸 수가 제각각인 택배 상자와 같다. 겉에 라벨은 있어도 안에 든 물건은 상자마다 다르다.

      예문

      • API 응답은 JSON이라 반정형이어서 필요한 필드만 꺼내 데이터프레임으로 만들었다.
      • 서버 로그가 반정형이라 정규표현식으로 항목을 뽑았다.
      • 같은 JSON이라도 항목이 어떤 때는 있고 어떤 때는 없어 처리 코드가 복잡해진다.

      헷갈리는 용어 비교

      정형 데이터
      반정형 데이터는 구조를 데이터 안에 함께 적어 두기 때문에 형식이 조금씩 달라도 읽을 수 있다. 정형 데이터는 구조가 먼저 정해지고 데이터가 거기에 맞춰진다.
