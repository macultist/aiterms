      CI/CD

      continuous integration and continuous delivery실무

      다른 이름: 지속적 통합, 지속적 배포, 지속적 통합 및 배포

      뜻풀이

      쉬운 AI 사전

      1. [명사] (코딩) 코드를 고칠 때마다 자동으로 검사하고 문제가 없으면 서비스에 올려 주는 자동화 체계.

      실무 AI 사전

      1. [명사] (코딩) 코드가 바뀌면 자동으로 빌드하고 테스트하고 배포한다. AI에서는 모델 평가나 프롬프트 회귀 테스트를 이 흐름에 넣어, 점수가 떨어지는 변경은 배포 전에 막는다.

      전문 AI 사전

      1. [명사] (코딩) CI는 변경 사항을 자주 통합해 자동 빌드와 테스트로 검증하는 방식이고, CD는 검증된 산출물을 운영 환경까지 자동으로 전달(Delivery) 혹은 배포(Deployment)하는 방식이다. MLOps에서는 데이터와 모델 검증 단계까지 포함한다.

      관용구/함께 쓰는 말

      • 빌드 깨졌다 - 자동 검사가 실패해 배포가 막힌 상태.
      • 파이프라인이 초록불 - 모든 자동 검사를 통과한 상태.

      쉬운 비유

      공장의 자동 검수 라인과 같다. 부품이 들어올 때마다 기계가 불량을 걸러내고 합격품만 출하장으로 보낸다.

      예문

      • 코드를 올리면 CI/CD가 자동으로 테스트하고 배포까지 해 준다.
      • 프롬프트를 바꾸면 CI/CD에서 평가 세트를 돌려 점수가 내려가면 실패 처리한다.
      • CI/CD가 없던 때는 배포 날이 가장 긴장되는 날이었다.

      헷갈리는 용어 비교

      MLOps
      CI/CD는 코드 변경을 자동으로 검증하고 배포하는 소프트웨어 공통 기법이고, MLOps는 거기에 데이터, 모델 학습, 모니터링, 재학습까지 얹은 머신러닝 전체 운영 방식이다.
