      LLMOps

      large language model operations실무

      다른 이름: LLM옵스, LLM 운영

      뜻풀이

      쉬운 AI 사전

      1. [명사] (인프라) 챗봇 같은 거대 언어 모델 서비스를 안정적으로 굴리고 계속 좋아지게 관리하는 일.

      실무 AI 사전

      1. [명사] (인프라) 프롬프트 버전 관리, 검색(RAG) 구성 점검, 응답 품질 평가, 비용과 지연 감시, 안전 필터 운영 등을 포함한다. 모델을 직접 학습시키기보다 외부 모델을 호출하는 경우가 많아 프롬프트와 평가 데이터의 관리가 중심이 된다.

      전문 AI 사전

      1. [명사] (인프라) LLM 기반 애플리케이션의 개발부터 운영까지의 수명 주기 관리 방법론. 프롬프트와 체인의 버전 관리, 오프라인 평가와 회귀 테스트, 트레이싱, 토큰 비용 추적, 가드레일, 사용자 피드백 수집과 이를 활용한 개선 루프를 다룬다.

      관용구/함께 쓰는 말

      • 프롬프트 버전 관리 - 프롬프트 변경 이력을 남겨 문제가 생기면 되돌릴 수 있게 하는 것.
      • 트레이싱 - 요청이 거쳐 간 단계와 호출을 기록해 원인을 추적하는 것.

      쉬운 비유

      MLOps가 직접 재배한 농산물을 관리하는 일이라면, LLMOps는 납품받은 고급 재료로 요리를 내놓으며 맛과 원가를 매일 점검하는 일이다.

      예문

      • 프롬프트를 바꿀 때마다 평가 세트로 점수를 비교하는 LLMOps 절차를 만들었다.
      • LLMOps 도구로 응답마다 사용한 토큰과 비용을 추적한다.
      • 모델 버전이 올라가자 답변 형식이 달라져서 LLMOps 팀이 회귀 테스트를 돌렸다.

      헷갈리는 용어 비교

      MLOps
      MLOps는 모델 학습 파이프라인과 데이터 관리가 핵심이고, LLMOps는 프롬프트, 검색, 평가, 토큰 비용 관리가 핵심이다. 둘은 겹치는 부분이 많아 MLOps의 하위 갈래로 보기도 한다.
