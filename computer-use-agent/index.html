      다른 이름: 컴퓨터 유즈, 브라우저 에이전트, 오퍼레이터

      뜻풀이

      쉬운 AI 사전

      1. [명사] (에이전트) 화면을 보고 마우스, 키보드를 직접 움직여 사람처럼 컴퓨터를 조작하는 AI.

      실무 AI 사전

      1. [명사] (에이전트) 스크린샷을 입력받아 클릭, 입력 동작을 출력하는 에이전트. 웹 예약, 폼 입력, 레거시 시스템 자동화에 쓰이며 보안, 승인 절차 설계가 필수다.

      쉬운 비유

      내 자리에 앉은 비서가 화면을 보면서 마우스를 클릭하고 키보드로 글자를 입력해 일을 처리하는 것과 같다. 전용 연결 통로가 없어도 사람처럼 화면으로 조작한다.

      예문

      • 컴퓨터 사용 에이전트에게 항공권 비교 검색을 맡겼다.
      • 컴퓨터 사용 에이전트가 결제 직전 단계에서 멈추고 사용자의 승인을 기다리도록 설정했다.

      헷갈리는 용어 비교

      도구 호출
      도구 호출은 AI가 미리 정해진 함수나 API를 직접 불러 쓰는 방식이라 빠르고 정확하다. 컴퓨터 사용 에이전트는 화면을 보고 클릭하는 방식이라 API가 없는 프로그램도 다루지만 느리고 오류 가능성이 더 크다.
      MCP
      MCP는 AI가 외부 도구와 데이터에 연결되는 표준 규격이다. 컴퓨터 사용 에이전트는 그런 연결 없이 화면 조작으로 일을 하는 방식이라 접근 경로가 다르다.
