      뜻풀이

      쉬운 AI 사전

      1. [명사] (데이터) AI가 공부할 때 쓰는 자료. 사진과 정답을 짝지어 놓은 연습 문제집과 같다.

      실무 AI 사전

      1. [명사] (데이터) 모델 파라미터를 업데이트하는 데 쓰이는 데이터. 양과 품질, 대표성이 모델 성능과 편향을 좌우하며, 저작권과 개인정보 문제도 이 단계에서 따져야 한다.

      전문 AI 사전

      1. [명사] (데이터) 손실 함수를 계산하고 경사 하강법으로 파라미터를 갱신하는 데 쓰는 표본 집합. 전체 데이터에서 검증, 테스트와 겹치지 않게 분리하며, 추정하려는 분포를 대표하는 것이 일반화의 전제다.

      관용구/함께 쓰는 말

      • 학습 데이터 구축 - 모델 학습을 위한 데이터를 모으고 정제하고 라벨링하는 일.
      • 학습 데이터 편향 - 학습 데이터가 특정 집단이나 상황에 치우친 상태.

      쉬운 비유

      수험생의 연습 문제집과 같다. 연습 문제만 달달 외우면 시험에서 처음 보는 문제를 못 풀 수 있다.

      예문

      • 학습 데이터에 한쪽 성별 사례만 많았다면 모델 결과도 한쪽으로 치우친다.
      • 학습 데이터가 부족해 데이터 증강을 도입했다.
      • 학습 데이터에 포함된 문서의 저작권 문제가 논란이 되었다.
